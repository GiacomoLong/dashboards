# 🗺️ Oasi Urbane — Mappa dei luoghi di refrigerio nelle città italiane

Dashboard interattiva per la localizzazione dei luoghi di refrigerio urbano nei 107 capoluoghi di provincia italiani. Permette di visualizzare su mappa parchi, fontanelle, piscine e altri spazi pubblici utili per affrontare il caldo estivo.

- **Selettore città** — menu a discesa con i 107 capoluoghi di provincia italiani
- **Geolocalizzazione indirizzo** — inserisci un indirizzo per visualizzare un marker "Tu sei qui" sulla mappa
- **Mappa interattiva** del territorio comunale con confine amministrativo
- **Layer selezionabili** tramite checkbox: parchi, giardini, aree nuoto, piscine pubbliche, fontanelle, biblioteche, farmacie e ripari

Dati geografici: OpenStreetMap via osmnx
https://www.openstreetmap.org

# 🗺️ Urban Oases — Map of Cool Spots in Italian Cities

Interactive dashboard for locating urban cooling spots across all 107 Italian provincial capitals. It allows users to visualize parks, drinking fountains, pools and other public spaces useful for coping with summer heat.

- **City selector** — dropdown menu with all 107 Italian provincial capitals
- **Address geolocation** — enter an address to display a "You are here" marker on the map
- **Interactive map** of the municipal area with administrative boundary
- **Selectable layers** via checkbox: parks, gardens, swimming areas, public pools, drinking fountains, libraries, pharmacies and shelters

Geographic data: OpenStreetMap via osmnx
https://www.openstreetmap.org
